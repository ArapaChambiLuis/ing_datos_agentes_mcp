# ing_datos_agentes_mcp
En esta sesión construimos un agente de ingeniería de datos que hace ese recorrido desde lenguaje natural. Un host MCP se conecta a seis MCP servers: gobierno con Amazon DataZone, calidad y procesamiento con AWS Glue, EMR y Athena, warehousing con Amazon Redshift, diagnóstico de Spark con el Spark History Server y documentación oficial de AWS
